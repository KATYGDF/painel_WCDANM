Teste Univariado 0 Baseline metodológico — mistura Gaussiana univariada com médias bem espaçadas, pesos desbalanceados como nos dados reais (50/25/20/5) e sobreposição leve (σ = 5), avaliada por AIC, BIC, ICL, AIC3 e Bootstrap LRT via flexmix

Teste de controle da série univariada. Configura uma situação próxima do ideal — distribuição Normal, médias bem espaçadas, sobreposição leve — porém com a mesma estrutura de pesos da simulação calibrada do projeto (G4 raro, 5 %). O propósito é demonstrar empiricamente que a metodologia recupera os quatro grupos quando seus pressupostos são respeitados, e que nem a rarefação de um grupo nem sobreposição leve são suficientes, isoladamente, para comprometer a recuperação. Isso permite, por exclusão, identificar a combinação responsável pelo fracasso do Teste Univariado 2.

Pergunta investigada: sob distribuição Gaussiana com médias bem espaçadas (μ = 10, 30, 50, 70), σ constante = 5 e pesos desbalanceados \(\pi = (0{,}50;\ 0{,}25;\ 0{,}20;\ 0{,}05)\), os cinco critérios — AIC, BIC, ICL, AIC3 e Bootstrap LRT — recuperam corretamente os quatro grupos verdadeiros? O grupo raro G4 (5 % da população) é classificado com sensibilidade aceitável?

1 · Motivação e posicionamento na série

A série de testes univariados foi construída como um experimento pedagógico em três degraus, mapeando como cada característica dos dados reais de saúde afasta a recuperação da estrutura latente da situação ideal:

Teste Distribuição Pesos Sobreposição Resultado esperado
Teste 0 (este) Gauss σ = 5 real (50/25/20/5) leve Recupera g = 4
Teste 1 NB(θ = 2,5) balanceado moderada BLRT recupera g = 4
Teste 2 NB(θ livre) real forte (calibrado ANS) Todos os critérios falham (g* = 2)

Cada degrau introduz um elemento de realismo, mantendo os demais controlados. O presente Teste 0 fixa as características ideais sobre a distribuição (Gauss) e a separação (médias espaçadas, σ moderado), mas adota a estrutura realista de pesos (G4 com apenas 5 % da população).

Por que esse desenho. Se este teste recuperar corretamente \(g = 4\), pode-se concluir, por exclusão, que nenhuma das duas características isoladas — rarefação de um grupo ou sobreposição leve — é responsável pelo fracasso da análise univariada nos dados reais. A causa estará restrita à combinação de sobredispersão da Binomial Negativa com sobreposição substancial das distribuições marginais — exatamente a configuração documentada na análise multivariada principal.

Achado A Os quatro critérios penalizados (AIC, BIC, ICL, AIC3) concordam em \(g^* = 4\). Os ganhos de log-verossimilhança são substanciais nas transições \(g = 2 \to 3\) (Δ\(\ell\) = 160) e \(g = 3 \to 4\) (Δ\(\ell\) = 132), suficientes para superar a penalidade BIC (\(\approx 12{,}8\) por parâmetro adicional) com folga. 5 · Resultados — Módulo B · Bootstrap LRT

O Bootstrap LRT (McLachlan, 1987) opera por reamostragem paramétrica sob \(H_0\) — método de referência para seleção de \(g\) em misturas quando as condições de regularidade do χ² assintótico não se sustentam.

Figura 3. Distribuições bootstrap da estatística LRT sob \(H_0\) para cada par sequencial \((g,\ g+1)\). Os LRTs observados em \(g = 2 \to 3\) (LRT = 320) e \(g = 3 \to 4\) (LRT = 265) são substanciais, mas a distribuição nula apresenta caudas longas com observações esparsas tão extremas quanto o observado, resultando em p-valores borderline (0,10 e 0,067).

Achado B (atípico) O BLRT apresenta resultado borderline neste regime — patologia conhecida. Os LRTs observados (320 e 265 nas transições críticas) são enormes em magnitude absoluta, porém a distribuição bootstrap sob \(H_0\) ocasionalmente produz LRTs comparáveis, resultando em p-valores apenas marginalmente acima de 0,05. A explicação está em uma patologia documentada do BLRT em misturas Gaussianas: a verossimilhança é não-limitada sob \(\sigma\) variável por componente (um componente pode contrair-se sobre uma única observação, inflando artificialmente \(\ell\)). Isto contamina a distribuição nula bootstrap com caudas longas (McLachlan, 1987; McLachlan & Peel, 2000, cap. 6). Vale notar que este obstáculo é específico do BLRT em Gauss com \(\sigma\) livre — não afeta o Teste 1 (NB com \(\theta\) fixo) nem o Teste 2 (NB com \(\theta\) livre, onde a verossimilhança é limitada).
Verificação possível. Para confirmar o resultado, recomenda-se re-executar o BLRT com \(B = 199\) (ou maior) — o que reduziria a influência de bootstrap replicates espúrios isolados. Espera-se que p caia para \(\approx 0{,}03\) nas transições críticas. Alternativamente, restringir \(\sigma\) a ser comum entre componentes (\(\sigma_h = \sigma\)) elimina o problema na origem, ao custo de modelar a heterogeneidade de dispersão.

Síntese metodológica A passagem Teste 0 → Teste 1 → Teste 2 documenta como cada característica realista degrada a recuperação: Gauss → NB introduz sobredispersão e cauda longa; θ constante → θ livre adiciona heterogeneidade entre componentes; separação dramática → sobreposição forte reduz a informação discriminante marginal; pesos balanceados → desbalanceados pressionam a detecção de componentes raros. Cada teste introduz um eixo de realismo, e o desempenho do conjunto de critérios degrada proporcionalmente.
Domínios de validade dos critérios Os cinco critérios têm zonas de validade complementares:
  • Critérios penalizados (AIC, BIC, ICL, AIC3): ótimos em Gauss bem separada (Teste 0); falham progressivamente sob NB com ganho marginal (Teste 1) e sob sobreposição forte (Teste 2).
  • BLRT: ótimo em NB com θ fixo (Teste 1, onde detecta ganhos minúsculos); apresenta patologia conhecida em Gauss com σ livre (Teste 0); insuficiente quando o sinal verdadeiramente desaparece (Teste 2).
Isto significa que nenhum critério isolado serve em todos os regimes — e justifica o protocolo de avaliar os cinco conjuntamente como prática metodológica robusta.
Implicação central O fracasso do Teste 2 não pode ser atribuído isoladamente à distribuição NB (Teste 1 trabalha em NB e funciona), nem aos pesos desbalanceados (Teste 0 trabalha com 50/25/20/5 e recupera), nem à existência de sobreposição moderada (Teste 0 a comporta). A causa do fracasso é a combinação entre sobredispersão da NB e sobreposição substancial das distribuições marginais — precisamente o regime em que a univariância se torna insuficiente. Esse diagnóstico, obtido por exclusão, justifica empiricamente a abordagem multivariada adotada na análise principal (V3, 5 variáveis), onde a informação discriminante reside nas correlações entre variáveis e não em qualquer dimensão isolada.

9 · Conclusões

Conclusão 1 Os quatro critérios penalizados (AIC, BIC, ICL, AIC3) concordam em \(g = 4\). A recuperação substantiva, medida por ARI = 0,936 e Acurácia = 0,972, confirma a identificação correta da estrutura latente — quatro componentes Gaussianos com médias bem separadas e dispersão constante.
Conclusão 2 O ICL opera em sua zona de validade. Conforme Biernacki, Celeux & Govaert (2000) e Baudry (2015), o ICL é apropriado quando os componentes podem ser supostos bem separados — exatamente o caso aqui. Sua concordância com BIC, AIC e AIC3 em \(g = 4\) valida empiricamente seu domínio de aplicabilidade.
Conclusão 3 A rarefação per se não compromete a recuperação. G4 (5 % da amostra, n = 257) é identificado com sensibilidade 0,934, desmentindo a hipótese de que o desbalanceamento dos pesos seja o fator dominante no fracasso do Teste 2.
Conclusão 4 A sobreposição moderada per se também não compromete a recuperação. Com \(\sigma = 5\) e \(\Delta\mu = 20\) (separação padronizada de 4σ), há cauda compartilhada entre componentes vizinhos — porém suficiente estrutura discriminante para o modelo recuperar a partição com ARI = 0,94 e estabilidade bootstrap de 0,97.
Conclusão 5 (atípica) O BLRT exibe patologia em mistura Gaussiana com σ livre. Os p-valores nas transições críticas (\(g = 2 \to 3\): p = 0,10; \(g = 3 \to 4\): p = 0,067) ficaram borderline apesar dos LRTs observados serem enormes (320 e 265). A causa é o problema de modos espúrios — bem documentado em McLachlan (1987) e McLachlan & Peel (2000, cap. 6) — em que a verossimilhança Gaussiana com σ variável não é limitada. O resultado não invalida a recuperação substantiva (ARI = 0,94), apenas evidencia o domínio de aplicabilidade restrito do BLRT neste regime.
Conclusão 6 · domínios complementares dos critérios Os cinco critérios têm zonas de validade complementares ao longo da série univariada — penalizados em Gauss separada (Teste 0); BLRT em NB clean com ganho marginal (Teste 1); nenhum critério resolve subdeterminação estrutural (Teste 2). A prática metodológica robusta consiste em avaliar os cinco conjuntamente, sem privilegiar qualquer um a priori.
Conclusão 7 · diagnóstico final da série O fracasso da recuperação univariada nos dados reais (Teste 2) é causado pela combinação entre sobredispersão da NB e sobreposição substancial das distribuições marginais — não por nenhuma característica isolada. Esta é a justificativa empírica para a abordagem multivariada da análise principal: somente o uso combinado de cinco variáveis disponibiliza, via correlações, a informação discriminante que cada dimensão isolada não contém.

10.2 · Inicialização k-means + EM (Gaussian)

Diferentemente dos Testes 1 e 2 (que usam FLXMRnegbin), aqui usa-se o ajuste Gaussiano default do flexmix. A função fit_kmeans_em() roda k-means em valor diretamente (sem transformação log) e passa a partição como semente para o EM completo. 

# ── Ajuste via flexmix Gaussiano (default, sem FLXMRnegbin) ──────────────────
fit_kmeans_em <- function(k_val, seed = 200) {
  set.seed(seed)
  if (k_val == 1L) {
    return(tryCatch(suppressWarnings(flexmix(
      valor ~ 1, data = df, k = 1L,
      control = list(iter.max = 500, tolerance = 1e-7, minprior = 0.005)
    )), error = function(e) NULL))
  }
  km <- kmeans(df$valor, centers = k_val, nstart = 25, iter.max = 100)
  tryCatch(suppressWarnings(flexmix(
    valor ~ 1, data = df, k = k_val,
    cluster = km$cluster,
    control = list(iter.max = 500, tolerance = 1e-7, minprior = 0.005)
  )), error = function(e) NULL)
}

# ── Extração de métricas penalizadas ─────────────────────────────────────────
extrair_metricas <- function(fit) {
  if (is.null(fit)) return(NULL)
  ll <- as.numeric(logLik(fit))
  np <- attr(logLik(fit), "df")
  list(
    k_efetivo = fit@k,
    logLik    = round(ll, 2),
    np        = np,
    AIC       = round(-2 * ll + 2 * np, 2),
    BIC       = round(-2 * ll + np * log(N), 2),
    ICL       = round(ICL(fit), 2),
    AIC3      = round(-2 * ll + 3 * np, 2)
  )
}

10.3 · Bootstrap LRT paramétrico

Para Gauss, parameters(fit) retorna matriz 2×k com média (linha 1) e desvio-padrão (linha 2) por componente. A simulação paramétrica sob H₀ amostra de \(\mathcal{N}(\mu_h, \sigma_h^2)\) com pesos \(\pi_h\). 

# ── Simulação paramétrica sob H0 (Gaussiana) ─────────────────────────────────
simular_normal_mistura <- function(fit, n_sim) {
  pesos <- prior(fit)
  pars  <- parameters(fit)
  k     <- fit@k
  pars_m <- if (is.matrix(pars)) pars else matrix(pars, nrow = 2)
  mus    <- pars_m[1L, ]
  sigmas <- pars_m[2L, ]
  comp <- sample.int(k, size = n_sim, replace = TRUE, prob = pesos)
  y <- numeric(n_sim)
  for (h in seq_len(k)) {
    idx <- which(comp == h)
    if (length(idx))
      y[idx] <- rnorm(length(idx), mean = mus[h], sd = sigmas[h])
  }
  y
}

# ── BLRT: H0: k vs H1: k+1 ───────────────────────────────────────────────────
blrt_passo <- function(fit_k0, fit_k1, B = BLRT_B, nrep = BLRT_NREP, seed = 1000) {
  set.seed(seed)
  k0 <- fit_k0@k; k1 <- fit_k1@k
  lrt_obs <- 2 * (as.numeric(logLik(fit_k1)) - as.numeric(logLik(fit_k0)))

  ll_best_k <- function(df_b, k_val) {
    best <- -Inf
    for (i in seq_len(nrep)) {
      m <- tryCatch(suppressWarnings(flexmix(
        valor ~ 1, data = df_b, k = k_val,
        control = list(iter.max = 200, minprior = 0.005, tolerance = 1e-6)
      )), error = function(e) NULL)
      if (!is.null(m) && m@k == k_val) {
        ll <- as.numeric(logLik(m))
        if (!is.na(ll) && ll > best) best <- ll
      }
    }
    if (is.infinite(best)) NA_real_ else best
  }

  lrt_b <- vapply(seq_len(B), function(b) {
    y_b  <- simular_normal_mistura(fit_k0, N)
    df_b <- data.frame(valor = y_b)
    ll0  <- ll_best_k(df_b, k0)
    ll1  <- ll_best_k(df_b, k1)
    if (anyNA(c(ll0, ll1))) NA_real_ else 2 * (ll1 - ll0)
  }, numeric(1))

  lrt_v <- lrt_b[!is.na(lrt_b)]
  pval  <- (sum(lrt_v >= lrt_obs) + 1) / (length(lrt_v) + 1)
  list(k0 = k0, k1 = k1, lrt_obs = round(lrt_obs, 2),
       pval = round(pval, 4), B_valido = length(lrt_v), lrt_boot = lrt_v)
}

for (k0 in K_GRID[-length(K_GRID)]) {
  res <- blrt_passo(fits[[as.character(k0)]],
                    fits[[as.character(k0 + 1L)]],
                    B = BLRT_B, nrep = BLRT_NREP, seed = 1000 + k0)
  resultados_blrt[[as.character(k0)]] <- res
  if (is.na(k_blrt_escolhido) && res$pval > 0.05) k_blrt_escolhido <- k0
}

# Consenso entre critérios
votos <- c(AIC = k_aic, BIC = k_bic, ICL = k_icl,
           AIC3 = k_aic3, BLRT = k_blrt_escolhido)
